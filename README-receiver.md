# Share Stream — приёмник и Chat для Mac

1. Запустите **Share Stream Setup.app** из общего установщика. Он ставит приёмник,
   **Share Stream Chat.app**, VST3 и AU. В архиве Receiver обе аппки можно перенести
   вместе в `~/Applications`.
2. В приёмнике откройте **Settings → Audio output…**, выберите выход и буфер
   (начните с 128 samples). Приёмник открывает только аудиовыход, без микрофона.
3. Войдите в аккаунт или вставьте код приглашения и подключитесь к музыке.
   **Direct P2P** — прямой путь; **Relay** — передача через сервер.
4. Нажмите **Voice & screen**: отдельное приложение Chat откроет ту же комнату
   под тем же аккаунтом. Для разговора/экрана нажмите соответствующую кнопку.
5. Приглашения на username приходят в **Invitations**. Подтвердите вступление.
   Комнату можно также открыть по скопированному коду или прежней ссылке.

Вход общий у плагина, приёмника и Chat. Пароль может состоять из любых 3+ символов.
Комната и подключение музыки возвращаются после перезапуска; **Disconnect**
сохраняет музыку выключенной. Микрофон и экран автоматически не включаются.
Настройки и дополнительные действия открываются отдельными окнами.

Музыка, экран и голос используют отдельные транспорты с приоритетом
**музыка → экран → голос**, с адаптацией к перегрузке. Абсолютный приоритет зависит
от сети. Экран передаётся без системного звука. Для наушников используйте режим
**Headphones · unprocessed**, включённый по умолчанию.

Сервер: **stream.whitesquirrel.digital:48100 UDP**. Начните с сетевого буфера 40 мс;
на стабильной проводной сети попробуйте 10/5 мс. Код даёт доступ к комнате.

Текущая сборка — для macOS: Chat требует macOS 13+, музыка — macOS 12+,
Intel и Apple Silicon. Релизные приложения подписываются Developer ID владельца
проекта и проходят Apple notarization. После обновления перезапустите обе аппки
и DAW. Настройки аккаунта, комнаты и выхода сохраняются.
