# Share Stream — приёмник для Mac

1. Распакуйте архив. Перетащите **Share Stream.app** в Applications или запустите прямо из папки.
2. Нажмите **Audio output...**, выберите аудиовыход и буфер (начните с 128 samples).
3. Получите приглашение от отправителя. Нажмите **Paste invite**, затем **Connect**.
4. Статус **Direct P2P** означает прямую передачу; **Relay** — звук через сервер.

Микрофон не нужен: приложение открывает только аудиовыход и не запрашивает доступ к микрофону.
Код комнаты даёт доступ к прослушиванию, передавайте его в личном сообщении.
По умолчанию используется сервер **13.140.153.191:48100 UDP**.

Min. net buffer задаёт минимальный сетевой буфер. Начните с 40 мс; для стабильной
проводной сети попробуйте 10/5 мс. При опоздании пакетов буфер автоматически
растёт до 250 мс. Текущее значение видно рядом с RTT. Для уменьшения переподключитесь.

Приложение подписано Developer ID Application и одобрено Apple notarization;
ticket прикреплён к приложению. При первом запуске macOS может показать обычное
подтверждение открытия. Архив рассчитан на macOS 12+ (Intel и Apple Silicon).
